Built for keeping several things moving

The two things a terminal makes hard: running more than one agent at once, and knowing what any of them is doing.

Parallel tasks

Work across as many Grok Build sessions as you like from one board. Each connects to grok over ACP when you first send to it. Existing sessions are picked up from ~/.grok — nothing to import.

A readable timeline

Messages, thoughts, tool calls, shell output and plans in one stream. In All, your turns sit on the right like a chat. It follows a reply as it is written — and lets go the moment you scroll up to read something further back.

Where the credits go

Weekly usage with a per-product breakdown, a 7-day token series, and live tokens and cost while a turn is running.

Paste or drop files

Copy from Explorer and paste, or drag the files onto the composer — each becomes a chip pointing at the file where it already lives. Screenshots too. Nothing is copied to a second place.

A rail you can keep

One line per task, grouped by project. Pin what you keep coming back to, rename anything in your own words, archive what is finished — and open any of it in a second window.

Say the next thing now

You do not have to wait for a turn to finish. Send while the agent is working and the message waits in the timeline where it will run — reorder it, edit it, drop it, or interrupt the current turn and run it immediately.

Files and Git beside it

Browse the tree, preview a file, review the agent's hunks, stage or unstage them one at a time, and commit — without leaving the task.

Two steps

ZtidalCode never handles your credentials — it reuses the session grok login creates.

1

Install Grok Build

Needs SuperGrok, X Premium+, or SuperGrok Heavy. Then grok login once. 

# Windows — PowerShell
irm https://x.ai/cli/install.ps1 | iex
# macOS — Terminal
curl -fsSL https://x.ai/cli/install.sh | bash
2

Install ZtidalCode

Take the .exe on Windows — per-user, no administrator. On a Mac, open the .dmg and drag ZtidalCode to Applications; one universal build runs on Apple Silicon and Intel. It updates itself from then on. 

ZtidalCode_<version>_x64-setup.exe
ZtidalCode_<version>_universal.dmg

Things to know first

Easier to hear now than to discover later.

SmartScreen will warn you

Our installers carry no Authenticode signature, so Windows calls the publisher unknown. Check your download against SHA256SUMS.txt on the release. Updates from inside the app are minisign-signed and verified against a key compiled into the build, so one cannot be substituted even though these files are public.

Gatekeeper will block the first open on a Mac

The Mac build is ad-hoc signed — not Apple Developer ID signed, not notarized — so macOS refuses the first double-click. On macOS 14: right-click the app, choose Open, confirm. On macOS 15: after the refusal, System Settings → Privacy & Security → Open Anyway, then confirm once. Check the download against SHA256SUMS-mac.txt on the release first (shasum -a 256). In-app updates are minisign-signed and verified exactly as on Windows.

The agent cannot see images

grok does not accept images over the protocol. Attach a picture and it writes code to inspect it instead, which it is good at — so "read these files" works properly, while "what does this screenshot say" does not.
